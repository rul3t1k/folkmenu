# Folk Menu — Семейная кулинарная книга

Веб-приложение для хранения, систематизации и обмена домашними кулинарными рецептами. Проект сочетает эстетику винтажных кулинарных книг и рукописных архивов с современным функционалом каталогизации, поиска по ингредиентам и ведения списка покупок.

---

## Основной функционал

* **Личный кабинет кулинара:**
  * Просмотр и редактирование профиля (имя, контакты, биография, загрузка аватара).
  * Статистика картотеки: счетчики записанных рецептов, закладок в архиве и товаров в корзине покупок.
* **Работа с рецептами:**
  * Добавление и публикация собственных рецептов.
  * Система закладок («Избранное») для быстрого доступа к понравившимся блюдам.
  * Интерактивный список покупок (корзина ингредиентов).
  * Поиск по базе рецептов и фильтрация по ингредиентам.
* **Авторизация и безопасность:**
  * Регистрация новых пользователей и вход в аккаунт через БД.
  * Разграничение прав доступа к редактированию профилей и записей.

---

## Технологический стек

* **Backend:** PHP 8.x, фреймворк **Yii2**
* **База данных:** MySQL
* **Frontend:** HTML, CSS, JavaScript
